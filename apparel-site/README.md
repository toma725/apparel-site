# flow — あなたのペットで作る、オーダーメイドアパレル

ペットの写真からオリジナルのアパレル・服飾雑貨をお作りする受注制作ブランド **flow** の紹介サイト（静的サイト・HTML/CSS）。掲載写真は制作例、価格は税込のベース価格です。

## ファイル構成
- `index.html` … ページ本体（ヒーロー・コンセプト・注文の流れ・アイテム・サイズ・ストーリー・事業者情報・コンタクト）
- `styles.css` … 見た目（クリーム基調のデザイン・スマホ対応）
- `assets/` … 制作例の画像

## 編集の仕方
1. 商品は `<article class="card">…</article>` が1商品。増やす時はこのかたまりをコピペ
2. 画像付き商品は `assets/` に画像を置いて `<img src="assets/○○.jpeg">` を差し替え
3. 画像のない商品は `swatch` クラスの色ブロックで表示（`styles.css` の `.swatch-*` で色を調整）
4. Instagram / メールのリンクをフッターで自分のものに変更
